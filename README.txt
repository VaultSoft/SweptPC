SweptPC v1.0.1
Free Portable Windows PC Cleaner
by VaultSoft

-----------------------------------------
HOW TO USE
-----------------------------------------
1. Run SweptPC.exe
2. Click Scan to see how much space can be freed
3. Uncheck any categories you want to skip
4. Click Clean Selected to free the space

-----------------------------------------
WHAT IT CLEANS
-----------------------------------------
- Windows Temp Files
- Prefetch Cache (requires Admin)
- Windows Log Files
- Recycle Bin
- Google Chrome Cache
- Microsoft Edge Cache
- Firefox Cache
- Microsoft Teams Cache
- Discord Cache
- Windows Thumbnail Cache
- Windows Update Cache (requires Admin)
- Memory Dump Files (requires Admin)

-----------------------------------------
NOTES
-----------------------------------------
- Fully portable, no installation needed
- Run as Administrator to unlock all categories
- Companion app to PulseMonitor
