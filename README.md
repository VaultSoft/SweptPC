## What It Cleans

| Category | Details | Admin Required |
|---|---|:---:|
| **Windows Temp Files** | %TEMP% and C:\Windows\Temp | |
| **Prefetch Cache** | Windows app launch cache | ✓ |
| **Windows Log Files** | Old CBS, setup and error logs (30+ days) | |
| **Recycle Bin** | All drives | |
| **Google Chrome Cache** | Browser cache and code cache | |
| **Microsoft Edge Cache** | Browser cache and code cache | |
| **Firefox Cache** | Cache, startup cache and thumbnails | |
| **Microsoft Teams Cache** | Teams app cache and blob storage | |
| **Discord Cache** | Discord app cache and code cache | |
| **Windows Thumbnail Cache** | Explorer thumbnail database | |
| **Windows Update Cache** | Downloaded Windows Update files | ✓ |
| **Memory Dump Files** | Crash dump files | ✓ |

Categories marked ✓ are unlocked when running as Administrator.

---

## Key Features

| Feature | Details |
|---|---|
| **Scan before you clean** | See exactly how much space each category is using before deleting anything |
| **Selective cleaning** | Uncheck any category to skip it — you stay in control |
| **Admin-aware** | Detects privilege level and unlocks additional categories when run as Administrator |
| **Live progress** | Animated progress bar with per-category feedback as files are removed |
| **Bytes freed summary** | Shows total space reclaimed at the end of each clean |
| **Auto-updater** | Notifies you when a new version is available |
| **No install needed** | Fully portable — just run the `.exe`, nothing written to the registry |
| **Low footprint** | Lightweight PyQt6 UI, tiny executable, no background services |

---

## How to Use

1. **Run** `SweptPC.exe` (right-click → *Run as administrator* to unlock all categories)
2. **Scan** — click **Scan** to analyse your system and see how much space can be freed
3. **Select** — uncheck any categories you want to skip
4. **Clean** — click **Clean Selected** and watch SweptPC free the space

---

## Requirements

- Windows 10 or 11 (64-bit)
- No Python required — standalone `.exe`, no installation needed
- Run as Administrator to unlock Prefetch, Windows Update Cache, and Memory Dump cleaning
